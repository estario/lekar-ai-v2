Поправките и разширението на демото са приложени през Lovable. Историческият преглед описва първоначалната версия; поправките са в FIXES.md. Новото демо има три измислени сценария, шаблон и стил на отчета, резюме за пациента, чернова на направление и SOAP документ от проверени раздели. Промяна на източника прави документа остарял до ново генериране. Локално на крайния код минават 56/56 теста, TypeScript и production build. AI може да добави неподкрепено твърдение дори след уточняване на инструкциите; ръчният преглед остава необходим. Вижте SCRIBE-DEMO.md за изпълнените проверки и ограниченията.

## Локална разработка

Използвайте Bun и Node.js. Lockfile е `bun.lock`.

```sh
git clone https://github.com/estario/lekar-ai-v2.git
cd lekar-ai-v2
bun install --frozen-lockfile --ignore-scripts
bun run test
node node_modules/typescript/bin/tsc --noEmit
bun run build
bun run dev
```

Build и unit тестовете могат да се изпълнят без реални ключове. Работещите Cloud/Auth/AI/Soniox функции изискват отделно конфигурирана среда; вижте SETUP.md. Стек: TanStack Start, React, TypeScript, Tailwind CSS и Supabase.
